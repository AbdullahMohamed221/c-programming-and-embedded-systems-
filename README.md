## Overview

This repository contains my journey in **C programming**, **embedded systems**, and **low-level software development**.  
It includes practice projects, problem-solving exercises, embedded applications, and hands-on experiments focused on understanding how software interacts directly with hardware.

The goal of this repository is to strengthen:

- Low-level programming skills
- Embedded C development
- Problem-solving and debugging
- Memory and pointer manipulation
- Microcontroller programming concepts
- Efficient and optimized code design

This repository also serves as a portfolio for:
- Internship applications
- Embedded systems opportunities
- Robotics and mechatronics projects
- Technical skill showcase on LinkedIn
